> 欢迎来到模组《铁砧工艺：鹿+》的页面！模组是《铁砧工艺》的附属，以**秋枫之力**为主题，主要内容有：

* **秋枫合金**：由铜锭、陶瓦与秋枫成分（白桦叶、樱花叶、鹿角珊瑚等）合成的复合材料，是整套秋枫内容的基础
* **秋枫工具**：
  * **秋枫共振器**：长按右键蓄力，以共振之力破碎方块
  * **秋枫飘升机**：穿戴于胸甲栏即可获得创造飞行，飞行时消耗耐久
  * **秋枫大环刀**（三/五/七/九环）：通过锻造不断升级，拥有真实横扫与对亡灵生物的特攻
* **词条系统**：偏安、逐鹿、破竹、枭首、豪夺五种词条，赋予工具独特的能力
* **重锻面板**：锻星砧的接口方块，可配置筛选条件，自动重锻符合要求的天体
